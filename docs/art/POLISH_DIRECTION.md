# P-01 visual polish direction

保持已有角色 atlas、四视角与 24 态真实翻滚。角色和 Tile 不变形、不模糊；所有新增绘制使用 Nearest、整数原生像素坐标。教程键位是一张使用现有 palette 的透明 PNG，轮廓 alpha 仅 0/255。

- World Shift：角色局部固定像素序列溶解，地面以较弱强度呼应。现有 shift phase 的 0.25 秒输入锁与逻辑提交保持不变，目标世界再以 0.15 秒重现，总长约 0.4 秒。后 0.15 秒只是表现尾段，不额外锁输入。保留 GridPosition、CubeOrientation、Perspective。无全屏闪白、抖动、红屏或重噪点。
- Perspective：沿用既有 0.4 秒 easing、四个 90° 吸附点、60 px 拖动阈值、12% 预览和不足阈值的 0.18 秒回弹；补充场景边缘的小几何线段，成功提交才播放轻 cue。没有任意角度状态或新相机逻辑。
- Link：成立时两端同步短暂微亮，稳定后弱呼吸；断开约 0.5 秒淡去。线宽 1 个原生像素，不使用答案文字、箭头路径或危险告警。
- Tutorial：只保留初始 WASD、第一断路 Space、连接教学点 Q/E + 水平鼠标图标。初始 0.45 秒淡入，沿用原情境标志与成功后的淡出；R 恢复。放在地图下方。
- Complete：由原有 Exit 状态立即锁玩法并激活既有出口动画。0.4 秒停顿后开始低强度压暗，0.9–1.8 秒淡入标题、完成与 R 提示；约 1.8 秒结束。无奖励、评分或新菜单。
- Environment：地图外侧 8 个低透明度单像素点缓慢漂浮；Surface 使用偏自然 palette，Inner 偏冷。落地只增加很短的 1 px 阴影边缘反馈，不挤压 Sprite。Plate 沿用已验收的下降与门动画，并补短边缘反馈和声音。

F4 开关主要局部 FX，用于验证表现不决定玩法；世界色板与已验收的角色、机关动画仍属于基础可读信息。完成提示与教程保留。新玩家是否理解这些提示必须由首次玩家验证，不能用已知解法的自动或人工路线替代。
